# AI Game From Zero 🎮

**สอนใช้ AI สร้างเกมจากศูนย์ — ไม่ต้องเขียนโค้ดเก่งก็ทำตามได้**

Repository ประกอบคลิป YouTube ช่อง **เอ๊ะดิ** สำหรับคนที่อยากทดลองให้ AI ช่วยออกแบบและสร้างเกมแรกของตัวเอง

> เป้าหมายคือเกม Fantasy RPG 2D ขนาดเล็กในเว็บเบราว์เซอร์ ไม่ใช่ MMORPG ออนไลน์เต็มรูปแบบ ใช้ไอเดียและคำสั่งภาษาธรรมชาติเพื่อเริ่มทำเกมได้จริง

## สิ่งที่เราจะสร้าง

- เดินตัวละครด้วย WASD / ปุ่มลูกศร
- ฉากหนึ่งฉากในสไตล์ Fantasy RPG
- ศัตรู 1 ชนิด พร้อมระบบโจมตีและแถบ HP
- ชุดตัวละคร 2 แบบ หรือไอเทมอุปกรณ์หนึ่งชิ้น
- ระบบชนะ/เริ่มใหม่
- เล่นบนคอมผ่านเบราว์เซอร์ได้

**ทำทีละขั้น อย่าสั่ง AI สร้าง MMO ทั้งเกมใน Prompt เดียว**

## เตรียมตัว

1. ติดตั้ง [Node.js](https://nodejs.org/) และ [Git](https://git-scm.com/)
2. ติดตั้ง [Claude Code](https://code.claude.com/docs/en/overview) หรือใช้ AI Coding Agent ที่เข้าถึงโฟลเดอร์โปรเจกต์ได้ (อาจมีค่าบริการ)
3. เตรียม VS Code หรือโปรแกรมแก้ไขโค้ดที่ถนัด
4. สร้างโฟลเดอร์โปรเจกต์ใหม่ เปิด Terminal ในโฟลเดอร์นั้น แล้วเริ่ม Claude Code
5. คัดลอก Prompt **ทีละขั้น** จากไฟล์ [PROMPTS.md](PROMPTS.md)

สำหรับคนเพิ่งเริ่ม: อธิบายสิ่งที่ไม่เข้าใจให้ AI ฟังได้เลย เช่น "ขออธิบายเหมือนคนไม่เคยเขียนโปรแกรม พร้อมบอกว่าต้องคลิกตรงไหน"

## เริ่มอย่างไร

1. เปิด [PROMPTS.md](PROMPTS.md)
2. ใช้ **Prompt 0** ให้ AI ตรวจเครื่องและโฟลเดอร์ก่อน
3. ใช้ **Prompt 1** วางแผนระบบที่เล็กที่สุด
4. ใช้ **Prompt 2** สร้างเกมเดินได้ แล้วเปิดทดสอบด้วยตัวเอง
5. ใช้ **Prompt 3–5** เติมงานภาพ ศัตรู และชุดตัวละคร
6. หากมีข้อผิดพลาด ให้ใช้ **Prompt แก้บั๊ก** และส่งภาพหน้าจอ/ข้อความ Error ให้ AI
7. หลังทดสอบผ่านแต่ละขั้น ค่อย Commit ผ่าน Git

## เครื่องมือหลัก

- **Game:** [Phaser](https://phaser.io/) + JavaScript/TypeScript + Vite
- **AI Coding:** Claude Code หรือ Agent แบบใกล้เคียง
- **Version control:** Git + GitHub
- **Video editing/motion:** [Remotion Skills](https://github.com/remotion-dev/skills)
- **Voice-over:** [OpenRouter TTS](https://openrouter.ai/docs/guides/overview/multimodal/tts)

[awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills) เป็น **รายชื่อเครื่องมือผลิตวิดีโอ** ไม่ใช่ตัวสร้างเกม และไม่จำเป็นต้องลงทั้งรายการ เลือก Remotion Skills เพื่อทำกราฟิกประกอบคลิปเพียงตัวเดียวก็พอ

## สำหรับคนอยากลองเอง

- โค้ดเกมที่ AI สร้างและผลการทดสอบ ต้องเกิดจากการลงมือทำจริงในเครื่องของคุณ
- ถ้า AI บอกว่าทำสำเร็จ ให้เปิดเกมเองและตรวจทุกครั้ง
- ภาพ/เสียง/ฟอนต์/Asset ที่นำมาใช้ต้องมีสิทธิใช้งานและให้เครดิตตามเงื่อนไข
- **อย่าใส่ API Key หรือไฟล์ .env ลง GitHub**
- ชุด Prompt นี้เป็นคู่มือ ไม่ใช่การรับรองว่ามีเกมที่พัฒนาเสร็จแล้วใน Repo
