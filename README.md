# AI Game From Zero 🎮

**สอนใช้ AI สร้างเกม RPG จากศูนย์ ตัวละครเดิน 8 ทิศ เปลี่ยนชุดได้ ถืออาวุธได้ — ไม่ต้องเขียนโค้ดเป็น**

Repository ประกอบคลิป YouTube ช่อง **เอ๊ะดิ** · ทุก prompt ในคลิปอยู่ที่ [PROMPTS.md](PROMPTS.md) เรียงตามลำดับในคลิป

## สิ่งที่เราจะสร้าง

- เกม RPG 2D มองจากด้านบน เล่นในเว็บเบราว์เซอร์ (Phaser 3 + Vite + TypeScript)
- ตัวละครเดินได้ **8 ทิศ ทิศละ 8 เฟรม** แบบเกม RO
- ตัวละคร 3 ชั้นซ้อนกัน: **ตัวเปล่า + ชุด + อาวุธ** · กด `C` เปลี่ยนชุด (อัศวิน / จอมเวท / นักล่า) · กด `Q` เปลี่ยนอาวุธ (ดาบ / ไม้เท้า / ธนู)
- ต้นไม้ หิน หญ้า จาก asset ฟรี CC0 · ศัตรู 1 ชนิด · HP · แพ้แล้วเริ่มใหม่

## ต้องมีอะไร

1. [Node.js](https://nodejs.org/) (ฟรี)
2. AI ที่แก้ไฟล์ในเครื่องได้: **Codex** หรือ **Claude Code** (ต้องใช้แพ็กเกจเสียเงินรายเดือน)
3. AI วาดภาพ: Codex หรือ ChatGPT (ภาพตัวละครทั้งหมดในคลิปมาจากตรงนี้)
4. เว็บเบราว์เซอร์

## ลำดับที่ทำในคลิป

| ขั้น | ทำอะไร | ผ่านเมื่อ |
| --- | --- | --- |
| 0 | ตรวจเครื่อง | AI บอกเวอร์ชัน Node.js / npm ได้ |
| 1 | วางแผนเกมให้เล็ก | มี GAME_PLAN.md ที่บอกทั้งสิ่งที่ทำและยังไม่ทำ |
| 2 | เดินได้ก่อน (กล่องสีฟ้า) | กดลูกศรแล้วเดิน ชนขอบแล้วหยุด |
| 3 | ตัวเปล่าสีเนื้อ | ได้ตัวเปล่าบนพื้นชมพูม่วง ยืนกางแขนนิดหน่อย |
| 4 | ใส่ชุดด้วยการ "แก้ภาพ" ตัวเปล่า | ซ้อนกับตัวเปล่าแล้วหัวและเท้าตรงกัน |
| 5 | ท่าเดิน 8 ทิศจากภาพนำท่าเดิน | กดทแยงแล้วหันทแยง ขาสลับ ซ้าย = ขวากลับด้าน |
| 6 | ใส่ชุดบนแผ่นท่าเดิน | ทุกเฟรมเป็นคนเดียวกัน ขาไม่โผล่ |
| 7 | อาวุธ + โค้ดซ้อน 3 ชั้น | `C` / `Q` เปลี่ยนได้ อาวุธอยู่ในมือทุกเฟรม |
| 8 | asset ฟรี | license เป็น CC0 หรือใช้เชิงพาณิชย์ได้ |
| 9 | ศัตรู + ลองเล่นให้แพ้ | แพ้แล้วกด Enter เลือดกลับมาเต็ม |

## ถ้าทำใหม่ (บทเรียนจากคลิป)

1. ตัวเปล่าใส่สีที่ไม่ชนกับชุด (เสื้อกล้ามเทา + เกราะเงิน = ตัดแล้วอกเป็นรู)
2. แนบตัวเปล่าไปทุกครั้งที่เจน ไม่งั้น AI วาดคนใหม่
3. ล็อกท่าด้วยภาพนำท่าเดินก่อน แล้วค่อยให้ AI ระบายทับ — อย่าสั่งรูปเดียว 64 ท่า (ช่องเล็ก ขาไม่สลับ หันผิดทิศ)

## ข้อควรรู้

- ถ้า AI บอกว่าเสร็จ ให้เปิดเกมเล่นเองทุกครั้ง
- ภาพ เสียง asset ที่เอามาใช้ต้องเช็ค license: CC0 ใช้ได้ทุกแบบ · CC-BY ต้องให้เครดิต · Non-commercial ห้ามหาเงิน
- **อย่าใส่ API Key หรือไฟล์ .env ลง GitHub**
- ผลของ AI แต่ละเครื่องอาจต่างกัน prompt เป็นจุดเริ่มต้น ไม่ใช่สูตรรับประกัน
